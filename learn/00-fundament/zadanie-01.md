# Задание 00.1–00.2 — рабочее место и первый скрипт

Цель: настроить окружение так, как это делают в реальных проектах, и написать
первую программу без единой скопированной строки.

## Часть 1. Рабочее место

1. Установи Python 3.12 с python.org. При установке отметь галочку
   **Add python.exe to PATH** — без неё ничего не заработает из терминала.
2. Установи VS Code и расширение Python от Microsoft.
3. Создай папку проекта (не на Рабочем столе, а, например, `C:\dev\wwrptechbot`).
4. В терминале внутри папки создай виртуальное окружение и активируй его:

   ```
   python -m venv .venv
   .venv\Scripts\activate
   ```

   После активации в начале строки терминала появится `(.venv)`. Это значит,
   что пакеты ставятся в проект, а не «в систему целиком».
5. Поставь библиотеку своего бота и проверь установку:

   ```
   pip install pyTelegramBotAPI
   python -c "import telebot; print(telebot.__version__)"
   ```

**Сдано, когда:** команда напечатала номер версии, а не `ModuleNotFoundError`.

### Вопросы на понимание

- Зачем окружение нужно, если можно ставить всё глобально?

## Часть 2. Калькулятор наказания

Напиши `fines.py` — скрипт, который спрашивает номер статьи и печатает наказание.

Требования:

- Данные по статьям — в словаре прямо в коде (3–5 статей достаточно).
- Пользователь вводит номер статьи через `input()`.
- Вывод собирается f-строкой и выглядит как ответ бота, например:
  `Ст. 105 «Убийство» — срок 25 мес., штраф 150 000 $`.
- Если статьи нет в словаре — понятное сообщение, а не падение с ошибкой.

**Сдано, когда:** скрипт отрабатывает и на существующей статье, и на выдуманной,
и на пустом вводе (просто Enter) — во всех трёх случаях без traceback.
