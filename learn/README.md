# Учебный маршрут

Здесь лежат материалы к личному роадмапу «От промпта к прошивке».

- `roadmap.artifact.html` — исходник интерактивного роадмапа (публикуется как Artifact
  на claude.ai, поэтому в файле нет тегов `<html>`/`<head>`/`<body>` — их добавляет
  платформа при публикации). Отметки о пройденных модулях хранятся на сервере.
- `00-fundament/` — задания к этапу 00 «Фундамент Python».

## Как этим пользоваться

1. Открываешь роадмап, смотришь модуль, помеченный «сейчас».
2. Читаешь строку «Доказательство» — это и есть задание.
3. Открываешь **пустой файл** и пишешь руками. Не копипастишь.
4. Заработало — ставишь галочку. Не заработало — правило 20 минут.

Одна галочка = одна работающая программа, набранная тобой.
