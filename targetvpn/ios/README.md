# Приложение TargetVPN (iOS)

Тот же клиент, что и на Android: привязка подписки к устройству по HWID,
статус подписки, выдача ключа подключения. Написан на SwiftUI без внешних
зависимостей.

## HWID на iOS

Берётся `identifierForVendor` вместе с моделью устройства, от них считается
SHA-256. Значение дополнительно кладётся в Keychain, поэтому переустановка
приложения не сбрасывает привязку — иначе `identifierForVendor` менялся бы после
удаления всех приложений разработчика.

Честное отличие от Android: полный сброс устройства или восстановление из
резервной копии на другой телефон могут дать новый идентификатор. Привязка на
iOS чуть слабее, чем на Android, — это ограничение платформы, обходов у него нет.

## Сборка

Локально (нужен macOS с Xcode):

```bash
cd targetvpn/ios
brew install xcodegen
xcodegen generate
xcodebuild build -project TargetVPN.xcodeproj -scheme TargetVPN \
  -destination 'generic/platform=iOS Simulator' API_BASE=https://ваш-домен
```

Через GitHub Actions: Actions → **Build TargetVPN IPA** → Run workflow, указать
`api_base`. Сборка идёт на macOS-раннере, в артефактах появится неподписанный
`.ipa`.

Проект в репозитории не хранится: `.xcodeproj` генерируется XcodeGen из
`project.yml`, иначе он постоянно конфликтует при слиянии.

## Как раздавать приложение

Неподписанный `.ipa` нельзя просто скачать и установить — iOS этого не
позволяет. Варианты:

1. **Сайдлоад** (без вложений): пользователь ставит `.ipa` через AltStore или
   Sideloadly со своим Apple ID. Подпись живёт 7 дней, потом нужно обновлять.
2. **Аккаунт Apple Developer** ($99/год): подписываете сборку и раздаёте через
   TestFlight — до 10 000 тестировщиков, ссылка-приглашение, обновления сами.
   Для этого в workflow добавляются сертификат и профиль в секреты репозитория.
3. **App Store** — публикация VPN-приложения требует, помимо аккаунта, ещё и
   документов: Apple проверяет такие приложения строже обычного.

Реалистичный путь — TestFlight.

## Подключение

Приложение получает от сервера ключ `vless://` и открывает его в установленном
клиенте (Streisand, V2Box, Shadowrocket). Своё VPN-ядро на iOS запускается
только через Network Extension, а она доступна лишь с платным аккаунтом
разработчика — поэтому сейчас работает передача ключа, как и на Android.
