# Приложение TargetVPN (Windows)

Консольный клиент на Go: привязывается к компьютеру по HWID, забирает ключ с
сервера, поднимает ядро Xray локально и переключает системный прокси на него.

## Как это работает

1. При первом запуске просит код привязки из мини-аппа и обменивает его на
   постоянный токен. HWID считается из `MachineGuid` реестра и имени машины,
   на сервер уходит только SHA-256.
2. Проверяет подписку и получает свежий ключ `vless://`.
3. Скачивает ядро Xray с GitHub (около 30 МБ, только в первый раз) в
   `%APPDATA%\TargetVPN\core`.
4. Поднимает локальные входы SOCKS5 `127.0.0.1:10808` и HTTP `127.0.0.1:10809`
   и включает системный прокси Windows на HTTP-вход.
5. По Ctrl+C или закрытию окна выключает прокси и останавливает ядро.

Режим прокси, а не TUN: трафик браузеров и программ, уважающих системный
прокси, идёт через VPN. Приложения, которые ходят мимо системных настроек
(часть игр и клиентов), останутся напрямую — для полного туннеля нужен
драйвер TUN, это отдельный этап.

## Сборка

```bash
cd targetvpn/windows
GOOS=windows GOARCH=amd64 go build -trimpath \
  -ldflags "-s -w -X main.apiBase=https://ваш-домен" -o targetvpn.exe .
```

Через GitHub Actions: **Build TargetVPN EXE** → Run workflow → указать `api_base`.

Тесты разбора ключа:

```bash
go test ./...
```
